# Manuel d’utilisation — Administrateur du centre

**EduCore · Guide pour débuter**
Version du 8 octobre 2026

## 1. Rôle de l’administrateur

L’administrateur du centre configure l’organisation scolaire et gère les dossiers du centre : années scolaires, salles, matières, enseignants, élèves et inscriptions, tarifs, paiements, dettes, emplois du temps, présences et évaluations. Les données sont propres au centre auquel le compte est rattaché.

Ce manuel concerne le profil **admin du centre**. Le **superadministrateur de plateforme** a un espace distinct pour gérer les centres et les paramètres de la plateforme (voir la section 15).

## 2. Préparer l’accès

Il faut un compte administrateur actif, l’adresse de connexion du centre et le mot de passe correspondant. Ouvrez EduCore dans un navigateur récent, entrez vos identifiants et cliquez sur **Se connecter**. En cas de refus d’accès, vérifiez l’adresse, le mot de passe et l’état du compte. Ne partagez pas un compte administrateur entre plusieurs personnes : chaque compte permet d’identifier les opérations effectuées.

Pour fermer la session, utilisez le menu de profil en haut de l’écran et choisissez la déconnexion. Sur un téléphone, le menu latéral s’ouvre avec le bouton de menu.

## 3. Repères dans le menu

- **Tableau de bord** : vue synthétique de l’activité du centre.
- **Planning** : création et consultation des créneaux par salle.
- **Structure pédagogique** : **Salles**, **Enseignants**, **Années scolaires**, **Matières**.
- **Élèves** : liste et dossiers, **Tarifs**, **Dettes / Relances**.
- **Présences** : vue consolidée et détails par salle.
- **Évaluations** : liste, détails et saisie des notes.
- **Espace Enseignant** : accès aux écrans de l’espace enseignant pour consultation ou assistance.
- **Profil utilisateur** : informations du compte.

Les fonctions de gestion du centre sont réservées au rôle admin. Les liens et boutons peuvent différer selon les droits et le contexte du compte.

## 4. Ordre de mise en place recommandé

Configurez d’abord l’année scolaire, puis les matières et les salles. Associez les matières aux salles et les enseignants aux matières/salles selon les écrans disponibles. Ensuite, enregistrez les élèves et leurs inscriptions, configurez les tarifs, puis préparez l’emploi du temps et les évaluations. Cet ordre limite les listes incomplètes lors des inscriptions, appels et saisies de notes.

## 5. Tableau de bord et contrôle quotidien

1. Ouvrez **Tableau de bord → Vision globale**.
2. Consultez les indicateurs présentés (effectifs, enseignants, paiements et assiduité selon les données disponibles).
3. Cliquez sur les rubriques correspondantes pour traiter les éléments qui nécessitent une action.

Le tableau de bord est une synthèse. Pour consulter ou modifier un dossier, ouvrez son module détaillé.

## 6. Années scolaires

Ouvrez **Structure pédagogique → Années scolaires**. Utilisez le bouton de création pour renseigner les informations demandées, notamment le libellé et les dates si ces champs sont présentés, puis enregistrez. Pour corriger une année existante, ouvrez son action de modification, mettez à jour les champs et enregistrez. Vérifiez ensuite qu’elle apparaît dans la liste et que les nouveaux dossiers utilisent la bonne année.

**Attention :** avant de modifier ou supprimer une année utilisée, vérifiez les conséquences sur les inscriptions et les résultats associés. Si la liste propose l’archivage/restauration, privilégiez cette action pour conserver l’historique.

## 7. Matières et salles

### Gérer les matières

Ouvrez **Structure pédagogique → Matières**. Ajoutez une matière en renseignant les champs demandés, puis enregistrez. Pour modifier une matière, utilisez son action de modification dans la liste. Une matière doit ensuite être associée aux salles où elle est enseignée.

### Créer et organiser les salles

1. Ouvrez **Structure pédagogique → Salles** et choisissez l’action de création.
2. Renseignez le nom ou code de la salle et les autres informations demandées.
3. Enregistrez, puis ouvrez la fiche de la salle.
4. Consultez les onglets ou sections de la fiche, notamment les élèves et les matières.
5. Ajoutez les matières pertinentes et vérifiez les coefficients lorsqu’ils sont demandés.

Les matières associées et leurs coefficients sont utilisés pour organiser les enseignements et les résultats. Contrôlez ces paramètres avant la création des évaluations. Si une salle n’est plus utilisée, utilisez son action d’archivage si elle est proposée ; réactivez-la depuis la liste si nécessaire.

## 8. Gérer les enseignants

Ouvrez **Structure pédagogique → Enseignants**.

1. Utilisez **Ajouter** ou le bouton de création.
2. Saisissez les informations demandées : identité, coordonnées et adresse e-mail notamment.
3. Enregistrez le dossier et vérifiez la fiche créée.
4. Ouvrez la fiche de l’enseignant pour examiner ses informations et ses créneaux/affectations disponibles.
5. Communiquez les modalités d’accès à l’enseignant par le canal prévu par votre établissement.

La liste permet aussi d’ouvrir les détails et, selon le statut, de suspendre, réactiver ou exclure un enseignant. Ces actions peuvent empêcher ou rétablir l’accès. Vérifiez l’identité et la situation avant de les confirmer. La promotion ou rétrogradation vers le rôle administrateur modifie les droits : réservez-la aux personnes autorisées et de confiance.

## 9. Élèves, inscriptions et dossiers

### Enregistrer un nouvel élève

1. Ouvrez **Élèves → Liste des élèves** puis choisissez l’action d’ajout ou ouvrez le formulaire **Nouvelle inscription**.
2. Remplissez les champs obligatoires avec les informations fournies par la famille. Vérifiez soigneusement les noms, le numéro de téléphone et les coordonnées.
3. Sélectionnez la salle et l’année scolaire demandées lorsque ces choix sont présentés.
4. Renseignez les informations d’inscription et de paiement demandées par le formulaire.
5. Enregistrez, puis ouvrez le dossier de l’élève pour vérifier que l’élève et son inscription apparaissent correctement.

Un élève et une inscription sont des informations liées mais distinctes. Pour un élève déjà connu, vérifiez d’abord son dossier avant de créer un nouvel élève, afin d’éviter les doublons.

### Mettre à jour un dossier

Recherchez l’élève dans la liste, ouvrez sa fiche et utilisez l’action de modification correspondante. Vérifiez l’identité avant d’enregistrer. Pour une correction historique ou une suppression, vérifiez les règles internes du centre et l’impact sur les inscriptions, présences, notes et paiements. Si une option d’archivage/restauration est disponible, elle permet généralement de conserver l’historique.

### Partager l’accès parent, si nécessaire

Depuis la liste ou la fiche de l’élève, utilisez l’action de création du lien parent si elle est proposée. Vérifiez le bon élève avant de générer et transmettre le lien à son responsable légal par un canal privé. Le portail parent est en lecture seule et permet d’accéder aux informations autorisées de l’élève. Traitez le lien comme une information confidentielle.

## 10. Tarifs, paiements et dettes

### Configurer les tarifs

Ouvrez **Élèves → Tarifs**. Créez un tarif en saisissant les informations demandées, puis enregistrez. Utilisez l’action de modification pour corriger un tarif. Avant de changer ou désactiver un tarif déjà utilisé, vérifiez les inscriptions concernées et les règles financières du centre.

### Enregistrer un paiement

Ouvrez la fiche de l’élève ou le parcours d’inscription, puis utilisez l’action de paiement disponible. Vérifiez l’élève, le montant et les autres champs demandés (date, mode ou référence si présentés) avant de valider. Après l’enregistrement, retournez au dossier et confirmez que le paiement apparaît et que le solde est cohérent. Ne saisissez pas un paiement sans justificatif ou confirmation réelle.

### Suivre les dettes

Ouvrez **Élèves → Dettes / Relances**. Repérez les dossiers concernés, ouvrez la fiche de l’élève pour vérifier son solde et son historique, puis suivez la procédure de relance du centre. La liste est un outil de suivi ; confirmez toujours les paiements récents dans le dossier avant de relancer une famille.

## 11. Planning et emploi du temps

Ouvrez **Planning**. Sélectionnez la salle ou le filtre proposé, puis naviguez jusqu’à la période souhaitée.

### Ajouter un créneau

1. Lancez l’action d’ajout de créneau.
2. Choisissez la matière, la salle, le jour et les heures demandés.
3. Sélectionnez l’enseignant lorsqu’un champ d’affectation est disponible.
4. Vérifiez les informations et enregistrez.
5. Contrôlez le créneau dans le planning et dans l’emploi du temps de l’enseignant.

### Modifier, supprimer ou réutiliser

Sélectionnez le créneau à modifier, changez les informations nécessaires puis enregistrez. Vérifiez l’impact sur l’enseignant et la salle. L’interface propose également une exportation du planning et, selon la vue, la réutilisation de la semaine précédente. Avant cette réutilisation, vérifiez la semaine cible et les créneaux existants pour éviter les doublons ou conflits. Utilisez l’export PDF ou tableur proposé pour partager une copie ; vérifiez le fichier téléchargé.

## 12. Présences

Ouvrez **Présences → Vue consolidée & Alertes** pour consulter la situation par salle. Sélectionnez une salle pour ouvrir le détail et examiner les appels enregistrés.

Les enseignants effectuent normalement l’appel depuis leur emploi du temps. L’administrateur consulte les relevés et suit les absences. Si un appel est manquant ou incorrect, identifiez le créneau et l’enseignant, puis faites corriger l’information selon la procédure du centre. Ne modifiez pas un relevé sans vérifier la présence réelle et conserver la traçabilité requise.

## 13. Évaluations et résultats

### Créer une évaluation

1. Ouvrez **Évaluations → Liste des évaluations**.
2. Choisissez la création et renseignez les champs demandés (par exemple le titre, la salle, la date et les matières concernées).
3. Enregistrez et ouvrez le détail de l’évaluation.
4. Vérifiez que les bonnes salles et matières sont proposées aux enseignants concernés.

### Suivre la saisie

Ouvrez le détail d’une évaluation pour consulter les informations et les notes disponibles. Les enseignants saisissent les notes depuis leur propre espace pour les évaluations/matières qui leur sont attribuées. Une note est sur 20. Vérifiez les résultats avant toute communication ou édition de bulletin. Le coefficient dépend du paramétrage de la matière dans la salle.

Si une note est manquante, vérifiez d’abord la bonne évaluation, matière, salle et affectation de l’enseignant. Demandez la correction à la personne responsable plutôt que de créer une deuxième évaluation.

## 14. Profil et sécurité des données

Ouvrez **Profil utilisateur** pour consulter ou modifier les champs proposés. Protégez les données personnelles et scolaires : verrouillez votre session sur un poste partagé, n’envoyez pas de listes complètes par un canal public, et vérifiez le destinataire avant de partager un lien parent ou un export. Ne transmettez jamais votre mot de passe.

## 15. Espace superadministrateur (plateforme)

Cette section s’applique uniquement si votre compte porte le rôle **superadmin**. Ce profil n’est pas l’administrateur ordinaire du centre. Son menu comporte **Vue globale**, **Centres**, **Journal d’audit**, **Paramètres plateforme** et **Profil superadmin**.

- **Vue globale** : consulter les indicateurs de la plateforme.
- **Centres** : créer un centre, consulter la liste, archiver ou réactiver un centre et, si autorisé, entrer dans le contexte d’un centre.
- **Journal d’audit** : consulter les événements de plateforme accessibles au rôle.
- **Paramètres plateforme** : consulter et modifier les paramètres globaux proposés.

Quand le superadministrateur entre dans un centre, il doit vérifier le centre sélectionné avant toute opération et quitter ce contexte lorsqu’il a terminé. Les modifications de statut de centre et les paramètres globaux ont un effet large : vérifiez les valeurs et le centre cible avant validation.

## 16. Résoudre les difficultés courantes

| Problème                                       | Vérification / action                                                                                                                         |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Connexion refusée                              | Vérifier l’adresse et le mot de passe ; demander la vérification du statut du compte.                                                         |
| Une page ou un bouton est inaccessible         | Vérifier le profil connecté. Certaines fonctions sont réservées à l’admin ou au superadmin.                                                   |
| Une liste est vide                             | Vérifier l’année, la salle, le filtre et les éléments préalables (matières, affectations, inscriptions).                                      |
| Un doublon d’élève apparaît                    | Rechercher par nom, code ou téléphone avant toute nouvelle création ; ouvrir le dossier existant.                                             |
| Un enseignant ne voit pas son cours/évaluation | Vérifier son compte actif, ses affectations, la salle, la matière et la période.                                                              |
| Un paiement ou une note semble incorrect       | Ouvrir le dossier source, vérifier l’élève et les paramètres, puis corriger avec l’autorisation appropriée.                                   |
| L’enregistrement échoue                        | Lire le message affiché, vérifier les champs obligatoires et la connexion, puis réessayer une fois. Contrôler la liste avant un nouvel envoi. |

Pour demander de l’aide, transmettez à l’assistance le module concerné, l’action effectuée, le message exact affiché et l’heure approximative. N’envoyez pas de mot de passe ni de données personnelles inutiles.
